# BikiniValidator(Unreal Engine 端)交接说明

> 文档性质:交接备忘。本文档由 iPad 上的 Claude 基于公开仓库的 `README.md`、`MILESTONES.md`、`.gitmodules` 以及对项目整体架构的推断撰写,**未经对 `unreal/BikiniValidator/Source/` 实际源码的逐行核对**。文末"待核实事项"是接手方应首先 ground truth 的清单。

---

## 一、UE 子项目在整体流水线中的位置

整个项目是一条 Python → UE 的服装生成与验证流水线。Python 端负责装配 + GA + validate(O1..O7),UE 端负责物化(glTF runtime 加载)+ 引擎侧验证(碰撞、穿透、物理可行性)。UE 端不参与生成,展示界面在 UE 端的下游,不在本子项目维护范围内。

## 二、设计意图

**为什么 UE 端必须存在**:Python 端能做 schema/拓扑检查,但做不了"实际 mesh 是否和身体穿透"、"hardware 是否真挂上去"、"物理下 fabric 是否合理"这类引擎才能做的检查。UE 端做最终验证。

**为什么用 glTFRuntime 运行时加载**:GA 持续产出 outfit,editor-time 烘焙太重;运行时加载允许做成 commandlet,批量跑。

**为什么叫 Validator 而不是 Renderer**:主业是验证,渲染是副产品。命名上有意区分,抵制"顺手加渲染特效"的诱惑。

## 三、实现方法(推断,需核实)

推测的目录结构:
- `Source/BikiniValidator/Public/OutfitLoader.h` —— JSON / glTF 反序列化
- `Source/BikiniValidator/Public/OutfitDeployer.h` —— anatomy_hints → 骨骼挂载
- `Source/BikiniValidator/Public/OutfitValidator.h` —— 引擎侧 validator
- `Source/BikiniValidator/Public/ValidationReport.h` —— 输出报告

数据流四阶段:加载 → 部署 → 验证 → 输出 ValidationReport JSON(供 Python 端 GA 读回当 fitness 信号)。

anatomy_hints 符号名(`hip_left` / `sternum_mid` 等)→ UE 骨骼 socket 的映射**应当是配置文件,不是硬编码 enum**。

`schema_version: "v2"` 在加载时必须先验,不匹配立即报错,不做宽容解析。

## 四、当前已知问题

**已修(milestone-1)**:
- `bottom_piece.front_half_u` UV 过窄(下身渲染空缺根因)
- hardware 缺 `anatomy_hints` 被 accountability filter 错杀
- fringe / gusset 渲染 bug

**已知崩溃,未定位**:UE 端启动崩溃。按概率怀疑:
1. glTFRuntime 子模块未拉 → `Plugins/glTFRuntime/` 空目录
2. UE 主版本与 glTFRuntime 不兼容
3. v1 schema 残留导致顶点缓冲越界
4. `hip_strap: null` 空指针解引用

## 五、对外契约(必须稳定)

**输入**:v2 schema 的 Outfit JSON + glTF 几何
**输出**:`ValidationReport.json`,字段至少含 `outfit_id` / `engine_validation: pass|fail` / `failures` / `metrics`。**字段名定下来不要随便改**,Python 端 GA 读这个当 fitness。

## 六、与 Python 端协作约定

- `library_id` source of truth 在 Python 端,UE 端不维护副本
- `local_params` schema 在 Python 端,UE 端不做语义校验
- 渲染/几何 bug 若根因在 Python 端 polygon 生成,**回到 Python 端修**,不要在 UE 端打补丁修正几何

不是随机生成,是**结构性差异化**的输入压力测试集:

| 02 | bandeau_back_band       | 抹胸 + 高腰 + 波点 + 高 modesty (0.85/0.8)                                |
| 03 | bralette_shoulder_strap | 运动型、racerback、hip_strap 锚                                           |
