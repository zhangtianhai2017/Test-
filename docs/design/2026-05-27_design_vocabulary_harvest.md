# Swimsuit Design Vocabulary Harvest

**Harvested: 2026-05-27**
**Purpose:** Source vocabulary for the swimsuit auto-design generator, biased toward **highly imaginative, stylized, fantastical** output. Generic mainstream beach swimwear vocabulary is deliberately excluded — these axes are tuned to push the generator into avant-garde, fantasy, cyberpunk, ethnic, and alt-fashion territory where there is competitive value.

Each axis lists 30-60 tags. Where Chinese fashion vocabulary has a distinct term, both EN and CN are given. Tags are grouped within each axis by sub-family for legibility, but at use-time they should be flattened into a single tag pool per axis.

## Usage notes for the generator

1. **Per-design, sample 2-4 tags from each axis** — sampling all six axes always produces a coherent point in design-space (silhouette + mood + material + decoration + coverage + reference). Sampling just one or two collapses to incoherent or generic output.

2. **Axis 2 (mood) and Axis 6 (reference) are the highest-leverage tags.** When a generation feels generic, swap or add a tag from these axes first.

3. **Avoid stacking conflicting moods.** E.g. `solarpunk + cybergoth` will pull the diffusion model toward muddy compromise; `solarpunk + Heian-court + bioluminescent` is more productive because mood / register / material are orthogonal.

4. **Chinese tags are not just translations** — `国风未来`, `赛博汉服`, `江户花魁`, `重ね色目` etc. have specific aesthetic loads that English equivalents (`cyber-guofeng`, `Edo courtesan`) lose. For Chinese-language judges or prompts, prefer the CN form.

5. **Banned-on-purpose** (do NOT add back): basic, classic, everyday, minimal beachwear, modest, conservative, casual resort, generic triangle/halter/bandeau/push-up without modifier, jammer, racer-back competition. These were the explicit "drop" list and represent the market the project is *not* competing in.

6. **Tag rotation:** the harvest is biased toward 2026-relevant trends (techno-balletcore, blokette, gorpcore-tech-Y2K cross). Re-harvest annually — alt-fashion subcultures rotate fast.
